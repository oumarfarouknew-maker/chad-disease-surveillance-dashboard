# Chad Disease Surveillance Dashboard

## Overview

The Chad Disease Surveillance Dashboard is a public health analytics project developed with Microsoft Power BI. It explores recorded disease cases, regional patterns, and temporal trends to demonstrate how health data can support epidemiological monitoring and public health decision-making.

## Project Objectives

- Analyze recorded disease cases over time.
- Compare case counts across regions.
- Explore disease distribution and demographic patterns.
- Develop interactive epidemiological reporting.
- Demonstrate exploratory outbreak monitoring indicators.

## Dashboard Features

- Total recorded case indicators.
- Disease category summaries.
- Regional case comparisons.
- Daily case trend visualization.
- Interactive disease and region filters.
- Exploratory outbreak monitoring.
- Epidemiological analysis and data limitations.

## Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Epidemiology
- Public Health Surveillance

## Data

The dashboard uses a dataset containing disease category, region, date, age, and sex variables.

The dataset's provenance and whether it is synthetic or publicly sourced should be documented before publication. No personally identifiable health information should be published.

## Methodology

The project demonstrates descriptive epidemiological analysis, temporal trend exploration, regional comparisons, and exploratory monitoring of unusual increases in reported cases.

Recorded case counts are not equivalent to incidence rates. Calculating incidence requires appropriate population denominators. Exploratory alert thresholds do not independently establish the presence of an outbreak.

## Limitations

Results depend on data quality, completeness, reporting practices, and the period covered by the dataset.

The dashboard is a portfolio demonstration and should not be treated as an operational public health alert system without further validation.
